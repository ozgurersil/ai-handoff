---
name: handoff
description: >
  Saves a structured session-summary markdown file so another AI (or a fresh Claude session)
  can resume work without context loss. Trigger when: rate limit is approaching, the 5-hour
  usage limit is near, context window is almost full, user says "handoff", "save context",
  "session summary", "context dump", "save progress", "rate limit soon", or "wrap up session".
  Produces a timestamped .md file with project state, completed work, in-progress tasks,
  key decisions, modified files, next steps, and environment snapshot.
---

You are generating an AI-to-AI handoff document. Another AI will resume this work cold — it has zero context. Make the document self-contained and immediately actionable.

## Step 1 — Gather context

Before writing, collect from the conversation:
- What project/task is being worked on
- Working directory (check CLAUDE.md or infer from file paths seen)
- Git state (branch, last commit) — run `git status` and `git log --oneline -5` if in a git repo
- All files created or modified this session
- All decisions made and their rationale
- Current task state (what's done, what's in progress, what's blocked)
- Next concrete steps
- Any open questions or blockers

## Step 2 — Determine output path

Default: `./handoff-{YYYY-MM-DD-HHMM}.md` in the working directory.
If a `handoffs/` directory exists, use `./handoffs/handoff-{YYYY-MM-DD-HHMM}.md`.
Use the current timestamp in the filename.

## Step 3 — Write the file

Generate and save a markdown file with this exact structure:

## Step 4 — Confirm to user

After writing the file, tell the user:
- Filename and path of the saved handoff
- One-line summary of what was captured
- Suggested resume prompt: `"Continue from handoff: {filename}"`

Keep the confirmation short. Do not summarize the entire handoff in chat.
